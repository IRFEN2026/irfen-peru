# Lurín 2017 research closeout

This directory records a bounded research closeout for the 2017 Lurín flood sequence.

The closeout is intentionally non-operational. It preserves `RESEARCH_ONLY`, `production_use=false`, `production_ready=false`, `operational_alerting_enabled=false`, `decision_thresholds=null`, and `activation_gate=BLOCKED`.

The 06 March 2017 Cieneguilla no-damage entry remains unadjudicated and is not a verified negative control. The 14 March Antapucro flow is upstream event-day context and is not automatically transferred to Pachacámac, Cieneguilla or lower-Lurín impact reaches. Historical alert bands, model return-period discharges, academic rainfall estimates and secondary claims are not promoted to IRFEN thresholds.

The ANA 2025 GeoJSON used as partial geometry carries machine-readable RESEARCH_ONLY guards at collection and feature level so it can be mapped without becoming operational evidence. The Phase-2 map catalog is regenerated from that guarded geometry and remains non-operational.
