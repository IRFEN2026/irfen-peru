# Capturas antes/después · PR de rediseño de la pantalla del mapa (16-10-2026)

Rama huérfana solo con imágenes, para el PR `ui/map-panels-v0-1`. No contiene código y no se integra en `main`.

**Cómo se generaron:** `site/` de `main` (`8f76b58e`) frente a la rama `ui/map-panels-v0-1`, servidos en local y renderizados con Chromium (Playwright). Leaflet 1.9.4 se compiló localmente desde la etiqueta oficial `v1.9.4`. Los mosaicos externos (OSM y NASA GIBS) se sustituyen por una tesela neutra, porque el entorno de captura no tiene acceso a ellos; por eso el fondo aparece gris. Las geometrías son las reales del repositorio.
