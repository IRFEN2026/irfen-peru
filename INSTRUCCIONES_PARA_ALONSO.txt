IRFEN v0.5 — PASOS EN GITHUB

1. Crea un repositorio público, por ejemplo: irfen-peru
2. Sube TODO el contenido de esta carpeta manteniendo la estructura.
3. Settings > Secrets and variables > Actions > New repository secret
   Nombre: EARTHDATA_TOKEN
   Valor: tu token NASA Earthdata.
4. Settings > Pages > Build and deployment > Source = GitHub Actions.
5. Actions > "IRFEN — Actualizar IMERG y publicar" > Run workflow.
6. Cuando termine, GitHub mostrará la URL pública.

IMPORTANTE:
- Nunca pongas el token dentro del HTML, JSON o Python.
- Si el token caduca, genera otro y sustituye únicamente el Secret.
- Los umbrales y áreas de muestreo actuales son provisionales, no oficiales.
